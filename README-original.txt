How to install:
1. Upload index.html, styles.css, script.js, and the assets folder to the root of your GitHub repo.
2. Keep your existing /services/, /industries/, /contact/, sitemap.xml, and robots.txt files.
3. Commit the files and let Cloudflare Pages or GitHub Pages redeploy.

Hero video:
- Put your compressed MP4 here:
  assets/media/axonix-hero.mp4
- Recommended video length: 5 to 10 seconds
- Recommended file size: under 8 MB if possible
- Must be muted/ambient style: rack, cabling, cameras, warehouse, lights, or commercial facility
- The site will still work without the MP4 because the animated image fallback is already built in.
